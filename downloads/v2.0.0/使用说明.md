## 使用方法

1. 打开安装程序，选择安装位置和视频保存位置，点击“安装 / 修复”。安装过程中显示进度和阶段提示。
2. 安装成功后选择打开程序，或双击桌面“视频号下载助手”快捷方式。
3. 登录电脑微信并打开“发现 → 视频号”，助手会自动连接；也可以点击“连接视频号”。
4. 在“视频号”标签观看、切换和下载视频。搜索结果和新打开的视频可接入其他标签。点击“返回微信”或关闭助手，会归还原窗口。
5. 点击“设置”修改下载目录、迁移已有下载或开关广告过滤；保存后重新进入视频号页面。

需要安装电脑微信并登录。程序复用微信页面和服务，不包含独立微信账号系统，不是视频号创作者后台，也不是将微信完整源码复制到本程序。

## 下载与画质

只请求服务器提供的原视频源，不转码、不添加水印、不提供其他分辨率选项。作者已嵌入画面的水印会保留；原视频源不等于作者本地尚未上传的素材，也不会把低分辨率视频放大成真正高清。

下载由本机辅助服务完成，切换页面或关闭助手主窗口不会主动取消已创建的下载任务。查看完成状态时可以打开下载面板并滚动至列表顶部。修改目录时可选择迁移已有下载，重名文件自动改名。
