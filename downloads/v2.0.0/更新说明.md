# 视频号下载助手 v2.0.0

主界面重构为真实微信视频号窗口，设置移至独立入口。支持推荐视频观看、搜索结果和视频详情标签接入，关闭程序归还微信原窗口。

新增安装进度、安装完成打开提示、微信连接引导，以及设置中的广告过滤开关。仅处理官方明确标记的广告；无标记推广和视频内植入不保证识别。

修复当前视频资料同步、下载面板初始化顺序和页面重建时下载按钮缺失。保留原视频源下载、目录迁移、快捷方式和图标。

最终候选包已完成三次不同视频的真实下载，目标、原视频源、分辨率及整段音视频解码全部通过。设置开关实际保存并核对服务加载值。广告规则完成三轮 24 项边界测试，未覆盖所有真实广告投放形式。

需要已安装并登录电脑微信。本版未进行可信代码签名，Windows 发布者验证仍可能显示未知。首次扫码、跨电脑和整机重启未全面覆盖。
