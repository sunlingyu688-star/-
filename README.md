## 安装和使用

双击“视频号下载助手-v1.3.2.exe”，选择程序安装位置，点击“安装 / 修复”。安装包内含下载核心和辅助程序，无需旧版程序。安装后自动创建桌面快捷方式，程序运行文件、配置和日志保存在安装目录中。安装包可单独保存。

重新打开微信视频号页面，点击“下载原视频”即可直接下载。设置窗口可修改视频保存位置，点击“保存设置”生效。修改下载路径后，可以选择迁移已有视频，也可以只修改新下载位置或取消操作。
